Skripta za rubni usmjernik

ip address 127.0.0.1/8
!
interface eth0
 ip address 10.0.1.2/24
 ip ospf cost 5
!
interface eth1
 ip address 10.0.3.1/24
 ip ospf cost 1
!
interface eth2
 ip address 10.3.1.1/24
 ip ospf cost 7
!
router ospf
 router-id 3.3.3.3
 redistribute static
 redistribute connected
 redistribute rip
 network 10.0.1.0/24 area 0.0.0.0
 network 10.0.3.0/24 area 0.0.0.0
 network 10.3.1.0/24 area 3.3.3.3
!

Skripta za usmjernik u tranzitnom području (virtual link)

interface lo0
 ip address 127.0.0.1/8
!
interface eth0
 ip address 10.1.2.2/24
 ip ospf cost 1
!
interface eth1
 ip address 10.2.1.3/24
 ip ospf cost 1
!
router ospf
 router-id 5.5.5.5
 redistribute static
 redistribute connected
 redistribute rip
 network 10.1.2.0/24 area 1.1.1.1
 network 10.2.1.0/24 area 2.2.2.2
 area 1.1.1.1 virtual-link 2.2.2.2
!
